- Title: `Chat 与 Agent 模式现已上线`

## Markdown content

欢迎使用本次功能更新。现在创建新对话时，可以在页面顶部选择 **Chat** 或 **Agent** 模式。

### Chat 模式

适合日常问答、写作、翻译、总结和分析。它保持原有的对话体验，Terminal、工具和 Skills 不会默认开启。

### Agent 模式

适合需要多步骤执行的任务，例如检索资料、处理文件、调用工具或运行 Terminal。系统会展示执行进度、工具调用和结果；涉及权限或关键选择时，可能会请你批准或补充信息。

> **模式在创建对话时确定，并在整个对话中保持不变。** 如需切换模式，请新建对话。

### 模型和工具设置

- 新对话初始使用系统默认模型，你仍可自由选择其他可用模型。
- Chat 与 Agent 各自有独立的 System Prompt、Terminal、工具和 Skills 默认设置。
- 这些设置只是新对话的初始值；你可以在当前对话中临时调整。

### 记忆系统已启用

记忆可以保存对未来对话有帮助的偏好、事实和长期要求，让回答更连贯。系统不会把每条消息都自动当作记忆；你可以在 **设置 → 个性化 → 记忆** 中查看、添加或删除记忆。

### 建议用法

1. 普通交流和内容创作优先选择 Chat。
2. 需要工具、Terminal、文件处理或连续执行多个步骤时选择 Agent。
3. Agent 执行期间可随时查看进度；遇到批准或提问提示时，请确认后继续。
4. 如果任务方向发生变化，建议新建对话并重新选择模式。

感谢使用。如发现异常，请把对话链接、发生时间和可复现步骤反馈给管理员。
